# 公开源码发布准备清单

本文记录公开仓库的边界。勾选项表示代码仓库已经具备相应控制，不代表系统适合无人值守实盘。

## 已完成

- [x] AIOption 从原单体工作区导出为独立仓库。
- [x] 排除 `.env`、SQLite、账户缓存、备份、生产报告、订单数据和市场数据。
- [x] 删除个人生产域名、IP 和服务器同步脚本。
- [x] 券商 API、交易调度、自动交易调度和订单监控默认关闭。
- [x] Docker 使用非 root 用户并只向本机发布端口。
- [x] 提供中文主 README、英文 README、许可证、贡献指南、安全政策和行为准则。
- [x] 提供后端测试、前端构建、API 文档覆盖与仓库卫生检查。
- [x] 提供 GitHub issue / PR 模板、CI、Dependabot 和秘密扫描。

## 发布前由维护者确认

- [ ] 在 GitHub 创建仓库并检查可见性、描述、Topics 和默认分支保护。
- [ ] 确认所有第三方 SDK、行情订阅与截图素材允许公开分发。
- [ ] 在全新机器按 README 完成一次无凭证启动。
- [ ] 使用模拟券商账户完成一次端到端订单生命周期演练。
- [ ] 开启 GitHub secret scanning、Dependabot alerts 和私密漏洞报告。
- [ ] 创建首个 Alpha release，并附带已知限制和数据库迁移说明。

## 明确不包含

生产数据库、真实订单、账户凭证、Longbridge 本地账户目录、ThetaData 下载数据、内部研究报告、营销视频、云服务器拓扑和私有部署脚本均不属于公开仓库。

本仓库采用经过审计的干净源码快照作为首个提交，不继承原工作区的 Git 历史。这是有意的安全边界，避免历史提交中的已删除凭证、生产资料或无关项目被重新公开。
